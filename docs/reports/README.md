# Reports

Dated status and meeting reports. Technical documentation stays in `docs/*.md`.

## Naming

`YYYY-MM-DD_<topic>.md`, with the topic in lowercase and hyphenated, for example
`2026-11-09_conditional-fmpe-kinematics.md`.

## Index

Newest first. Add one line per report: date, then topic, linked to the file.

- 2026-11-11: [FMPE on the FR3 inverse-kinematics benchmark](2026-11-11_fr3-fmpe.md)
